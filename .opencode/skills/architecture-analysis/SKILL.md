# Architecture Analysis
Use for material architecture decisions or alternative comparisons. Distinguish facts, explicit requirements, approved constraints, implementation evidence, assumptions, and open questions.

Source precedence: explicit task requirements → approved ADRs → consistent diagrams → implementation evidence → assumptions. Proposed ADRs are context, not authority.

Workflow: define the decision → retrieve minimum evidence → identify constraints → compare realistic alternatives → evaluate explicit trade-offs → recommend → identify ADR/contract/diagram impact → state open questions.

Do not approve architecture, edit artifacts, or invent missing requirements.
